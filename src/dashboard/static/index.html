Using an existing prepared feature snapshot

Preprocessing and feature extraction will be reused. Patient/recording selection is fixed to that snapshot, including while new files are being downloaded. You can change patient roles and training settings. Changing signals, labels or features requires fresh preprocessing.

Preparation stores a reusable snapshot. Choose “Prepare reusable features” when it will later be used for training; choose diagnostics only to inspect preprocessing errors.
